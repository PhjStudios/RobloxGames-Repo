# YourGame

Roblox game developed using Luau, Rojo, GitHub, Rokit, StyLua, Selene, and Roblox Studio.

## Initial setup

1. Install Git, GitHub Desktop, VS Code, Roblox Studio, and Rokit.
2. Clone this repository.
3. Open the repository in VS Code.
4. Run `rokit install`.
5. Run `rojo plugin install`.
6. Run `rojo serve`.
7. Open the development place in Roblox Studio.
8. Open the Rojo plugin and connect.

## Development commands

- Start Studio synchronization: `rojo serve`
- Format code: `stylua src`
- Check code: `selene src`
- Test the project build: `rojo build -o build.rbxlx`

## Important rule

Scripts inside Rojo-managed folders are edited through VS Code or Codex, not Roblox Studio.
